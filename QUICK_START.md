# Quick Start Guide

Get up and running with the VPN Checker Backend in minutes.

## Installation

```bash
git clone https://github.com/kort0881/vpn-checker-backend.git
cd vpn-checker-backend
pip install -r requirements.txt
```

## Usage

```bash
python main.py
```
